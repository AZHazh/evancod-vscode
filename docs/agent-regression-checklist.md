# Agent 回归检查清单

每次修改提示词、上下文、工具协议或停止条件后，使用同一模型和 Provider 执行以下任务，
对比完成率、迭代次数、输入/缓存/输出 token、工具错误和最终验证结果。

1. 只读定位：查找一个跨模块调用链并给出文件与行号。
2. 单文件修改：完成小范围修复并运行对应检查。
3. 多文件修改：修改扩展端、共享类型和 Webview，完成编译与构建。
4. 失败恢复：先制造一次无效工具参数，确认模型能根据错误修正。
5. 长输出：运行产生超过 64 KB 输出的命令，确认能从归档文件读取中间段。
6. 长文件：分段读取超过 32 KB 的文件，确认不会遗漏目标内容。
7. 任务闭环：创建多个有依赖的任务，确认全部验证并完成复核。
8. 中断续跑：在工具调用后停止，再发送“继续”，确认不重复已完成工作。
9. Responses：确认正文、reasoning summary、工具调用和缓存 token 均正常显示。

硬性验收：核心工具集合不变；100 轮上限不变；协议错误为零；未完成和触顶不得标记完成；
任何被裁剪的工具原文都有明确、可读取的恢复路径。
